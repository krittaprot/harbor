# Harbor v1.5.0

The first downloadable Harbor release: a native macOS service manager for people and agents,
based on azu/launchd-ui and published under the MIT license.

## Download

- **Harbor_1.5.0_aarch64.dmg** — Apple Silicon Macs (M-series).
- **SHA256SUMS** — checksum for the DMG.
- Intel binaries are not included in this release.

## Install

1. Download and open the DMG.
2. Drag **Harbor.app** into **Applications**.
3. Launch Harbor from Applications. Quit an older running copy first.

This build is **ad-hoc signed, not Apple-notarized**. If macOS blocks it, first attempt to open
the app, then use **System Settings → Privacy & Security → Open Anyway** and confirm.
Only approve a download obtained from this repository.

To verify your download, place `SHA256SUMS` beside the DMG and run:

```sh
shasum -a 256 -c SHA256SUMS
```

## Included

- Grouped services, process trees, listening ports and HTTP/TCP health checks.
- Open-at-login inventory, restart readiness and snapshot comparisons.
- Native monochrome menu-bar icon, pinned services and notifications.
- Health wording that distinguishes passing checks from unchecked services.
- Temporary-process preferences and recognition of OpenCode's shared-service ownership.
- Adoption previews, live progress, rollback diagnostics and safe matching-plist retries.
- Copyable diagnostic reports and plist previews.
- Bundled headless CLI: inventory, diagnosis, adoption, archival and service controls.

```sh
/Applications/Harbor.app/Contents/MacOS/harbor status
/Applications/Harbor.app/Contents/MacOS/harbor diagnose opencode.exe
```

CLI output automatically becomes versioned JSON when piped or captured by an agent.
See [CLI documentation](https://github.com/krittaprot/harbor/blob/v1.5.0/docs/CLI.md).

## Current limitations

- Early development: installed startup/notification behavior and real reboot recovery still
  need broader owner acceptance. Restart readiness reflects configuration, not guaranteed recovery.
- Some defaults reflect the original development Mac, including `/Volumes/ProVault` and example
  groups. Configure groups, URLs, dependencies and pins in `services.toml`.
- The unloaded-agent count currently includes empty plist placeholders and explicitly disabled
  agents. It is an inventory count, not a count of broken services.
- Harbor runs without root; macOS may limit visibility into other users' processes and system jobs.

Upstream attribution and the MIT license are preserved.
