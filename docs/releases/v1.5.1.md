# Harbor v1.5.1

Fixes confusing scan errors and the old `launchd-ui` background-item name.

## Fixes

- Background startup registration is now named **Harbor**. The bundled GUI executable is
  `harbor-app`, and macOS display-name metadata explicitly says Harbor.
- On upgrade in the same installed app location, Harbor archives its own old `launchd-ui.plist`
  startup file before creating the new Harbor entry. Unrelated apps and custom startup entries
  are preserved. macOS may retain an old notification or loaded entry until you log out/in.
- Permission-denied plists, missing files, broken symlinks and invalid plists now have separate
  **Scan coverage** explanations and next steps instead of Rust debug error strings.
- Other services continue to be scanned. Skipped files are not treated as confirmed service
  failures. Raw technical details remain available, with **Copy scan report** for support.
- CLI JSON includes `diagnostics.inventory_issues`; readable output explains the skipped files.
  `harbor diagnose` accepts a skipped file's full path or filename without `.plist`.

The reported Teams warning means macOS denied file access. The Java warning means the plist
was missing when read; a dangling symlink is one possibility, not a confirmed cause from the
screenshot alone. Harbor does not change third-party file permissions or delete their files.

## Download and install

**Harbor_1.5.1_aarch64.dmg** is for Apple Silicon Macs (M-series). Download it, quit the old
Harbor, and drag Harbor.app into Applications to replace it. Launch the new copy there.

This build is **ad-hoc signed, not Apple-notarized**. If macOS blocks it after you try to open
it, use **System Settings → Privacy & Security → Open Anyway** for your trusted download.
`SHA256SUMS` is included; run `shasum -a 256 -c SHA256SUMS` beside the DMG to verify it.

The bundled CLI is `/Applications/Harbor.app/Contents/MacOS/harbor`. For example:

```sh
/Applications/Harbor.app/Contents/MacOS/harbor diagnose com.microsoft.teams.TeamsUpdaterDaemon
/Applications/Harbor.app/Contents/MacOS/harbor diagnose com.oracle.java.Helper-Tool
```

Known limitations from v1.5.0 still apply, including the original machine-specific defaults
and unloaded-agent classification. MIT license and upstream attribution are preserved.
