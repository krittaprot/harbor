# Harbor v1.5.2

Update Harbor from the app, with reliable Tailscale status in native launches.

## New: in-app updates

- Open **Settings → Software updates → Check for Updates**.
- Review the available version and release notes, then choose **Download & Install**.
- Harbor downloads the matching Apple Silicon or Intel archive from GitHub Releases
  and verifies its signature before replacing the app. Progress and retryable errors
  stay visible; navigating away from Settings does not discard the operation.
- Choose **Restart Harbor** after installation. Your settings and monitored services
  stay in place. macOS may request administrator permission to replace an app you do not own.
- Updates are user-initiated. Development builds and apps opened from a disk image can
  check for updates, but installation requires a release build in `/Applications` or
  `~/Applications`. Checks have a 30-second timeout; downloads have a five-minute timeout.

## Fixes

- Tailscale status works when Harbor is launched from Finder or at login, using a
  child-only CLI-mode environment override.
- **Rescan** refreshes Tailscale, FileVault and other system status immediately rather
  than waiting for the background cache to expire.

## Install this update once

v1.5.1 and earlier do not have an updater. Download the matching DMG from this release:

- **Apple Silicon (M-series):** `Harbor_1.5.2_aarch64.dmg`
- **Intel:** `Harbor_1.5.2_x64.dmg`

Quit Harbor, open the DMG, and drag **Harbor.app** into Applications, choosing **Replace**.
Reopen Harbor from Applications. Future releases can be installed from Settings.
Keep using the same installation location so existing login startup registration stays valid.

The app is **ad-hoc signed, not Apple-notarized**. If macOS blocks the trusted download,
try opening it, then use **System Settings → Privacy & Security → Open Anyway**.
Updater signatures verify release authenticity; they do not replace Apple notarization.
`SHA256SUMS` covers the DMGs, updater archives, signatures and manifest.

Existing user-level scan visibility, machine-specific defaults and login/reboot acceptance
limitations still apply. The bundled CLI remains at `Harbor.app/Contents/MacOS/harbor`.
